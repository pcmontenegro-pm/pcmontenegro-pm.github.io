The problem

Operations that didn't
scale with the channel.

When Karigab started hosting daily TikTok Live shows, their sales channel scaled overnight. Their operations didn't. Every order was managed manually across WhatsApp, mental notes, and spreadsheets that didn't talk to each other.

The result: duplicate orders from two customers claiming the same item with no stock lock. Payment validation done from memory. 30+ WhatsApp messages per live session answered manually from scratch. No daily visibility for the owner — no revenue figure, no order status, no stock risk.

What was built

Six components.
One system.

The constraint — non-technical team, zero budget, live operations that couldn't stop — meant the solution had to be built around what already existed. Every decision was tested against one question: can a non-technical operator run this alone?

01
SKU system & physical labelling
A four-part garment code (Category · Colour · Size · Number), printable on standard A4. The code travels from the physical tag to the WhatsApp conversation to the spreadsheet row.
Inventory · Operations
02
WhatsApp-native checkout flow
Six response templates replacing all manual writing. A pre-assigned order number used as payment reference.
UX · Payment Flow
03
Unified inventory — one source of truth
Two linked Google Sheets tabs (Orders/Stock) feeding one Available figure across physical and digital channels.
Data · Inventory
04
Batch bank reconciliation
A MATCH formula returning MATCH ✅, REVIEW ⚠️, or PENDING. Two 15-minute rounds per day replace 30+ individual per-payment bank checks.
Payment Validation · Reconciliation
05
Operations dashboard
A Summary tab showing the owner — in under 2 minutes each morning — today's revenue, unconfirmed orders, match exceptions, and critical stock alerts.
Visibility · Reporting
06
Role protocols & team playbook
Three explicit operational roles — owner, TikTok host, WhatsApp operator — each with a daily checklist, clear scope, and permissions in the shared spreadsheet.
Operations · Team Design
